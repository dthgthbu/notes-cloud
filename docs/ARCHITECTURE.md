# Структура проекта Notes Cloud

Notes Cloud — веб-приложение для создания и хранения личных заметок.

## Как устроен проект

Проект разделён на несколько основных частей:

- `app/` — основной код приложения.
- `tests/` — автоматические тесты.
- `data/` — база данных SQLite.
- `docs/` — дополнительная документация.

## Основные файлы

| Файл | Назначение |
|---|---|
| `app/main.py` | Запуск приложения и обработка API-запросов |
| `app/auth.py` | Регистрация, авторизация и проверка паролей |
| `app/database.py` | Работа с базой данных |
| `app/static/index.html` | Пользовательский интерфейс |
| `tests/test_api.py` | Проверка работы API |
| `CONTRACTS.md` | Описание API и структуры базы данных |

## Как работает приложение

1. Пользователь открывает приложение в браузере.
2. Через интерфейс отправляет запросы на сервер.
3. FastAPI обрабатывает запросы.
4. При необходимости сервер проверяет авторизацию пользователя.
5. Данные сохраняются или извлекаются из SQLite.
6. Результат возвращается пользователю.

## Безопасность

- Пароли хранятся в виде хэшей PBKDF2-SHA256.
- Для авторизации используются JWT.
- Токены хранятся в HttpOnly Cookies.
- Пользователи имеют доступ только к собственным заметкам.
- Секретные настройки хранятся в `.env`.

## Запуск

Приложение можно запустить локально через Uvicorn или с помощью Docker Compose.

Инструкции по запуску находятся в основном файле [README.md](../README.md).
